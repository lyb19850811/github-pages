AI 能做什么、不能做什么，答案藏在训练目标里。本文从第一性原理出发，把市面上流传的「四层分级」「行业分类」「几句实话」统一到同一条原理链上，校验它们的对错，给出一套可复用的选型判据。

## 结论先行

1. **根本原理**：LLM 是参数化的条件概率分布 $P(\text{next token} \mid \text{context})$，训练目标是最大化训练语料的似然。它优化的是「像不像」，不是「对不对」。
2. **四条判据**：正确性来源、反馈闭环、可回滚、终局责任。任务目标与训练目标的夹角决定适用度。
3. **三套框架自洽**：四层分级（强适用/次适用/慎用/不建议）、九行业分类、三句「实话」，都是这四条判据在不同切面上的投影，彼此印证、无矛盾。
4. **两处易错点**：①「量大」是双刃剑——它是自动化经济性的前提，同时是后果的乘数；② 正确粒度是「任务/环节」，不是「行业」。
5. **两条红线**：终局判定归人；数据出网受控。

## 一、根本原理：LLM 是条件概率分布

一个 LLM 就是一个参数化的条件概率分布

$$P(\text{next token} \mid \text{context})$$

训练目标是最大化训练语料上的似然（likelihood）。这条事实决定了几乎所有的「适合/不适合」：

- 训练信号只有 next-token 的交叉熵 loss，没有任何「外部真值」监督。
- 它学的是「下一个 token 像不像人写的」，不是「这个 token 对不对」。

下文四条推论都从这一条原理推出。

## 二、四条推论

### 2.1 推论一：它学的是「似然」，不是「真值」

- **翻译、摘要、改写**：任务的「正确输出」恰好等于「符合目标语言分布的高概率文本」。任务目标与训练目标**重合**，所以最稳。
- **精确计算、实时事实**：正确性由外部世界决定（$2+2=4$、今天的股价），不由语料频率决定。语料里可能「$2+2=5$」也出现过，模型学到的是「数字串之间的统计关联」，不是算术规则。任务目标与训练目标**正交**，所以会幻觉。

一句话：**「正确 ≈ 像样」的任务适合；「正确 = 符合外部事实」的任务必须外挂真值源。**

### 2.2 推论二：输出是「逐 token 采样的单遍前向」，错误会累积

自回归生成：$t$ 时刻只依赖已生成的 $t-1$ 个 token，没有「回头修改」的能力。前面的错误只能通过后面的 token「自圆其说」，不是修正。

- 传统求解器是 `loop until converge`：有收敛条件，错了能重算。
- LLM 是一次前向 + 逐 token 采样，**没有全局一致性检查**。这正是「越生成越长、越容易跑偏」的原理。

- **适合**：一步映射、短输出、结构固定（分类、抽取、短答案）。
- **不适合**：需要全局一致性、长链推理、迭代收敛（长文生成、复杂数学证明）。CoT 只是把「回头修正」**显式写进 token 流**，让模型用生成能力模拟推理，是补丁不是根治。

### 2.3 推论三：连续向量表示，无精确符号存储

知识存于权重和 KV cache，是连续的、近似的、可被注意力软擦写的。注意力的本质是「软寻址」——对所有位置加权求和，没有「精确读写某个地址」。

- **适合**：语义相似、模糊匹配、容错的任务（「这段话大概什么情绪」）。
- **不适合**：精确值、唯一标识、位级运算（大数乘法、精确 ID 回显、哈希）。连续空间里 $1000000007$ 和 $1000000008$ 是「几乎相同」的向量，模型很难把它们当两个离散符号精确区分。

### 2.4 推论四：泛化 = 分布内插值，不是外推

训练最小化的是训练分布上的期望 loss，学的是这个分布的几何结构。

- **分布内**（高频、有先例）：内插，可靠。
- **分布外**（长尾、新颖、对抗输入）：外推，不可保证——这是数学性质，不是「模型不够好」，换更大模型也救不了分布外。

- **适合**：常见场景、有大量先例。
- **不适合**：长尾、罕见、对抗性输入，必须加兜底/拒答。

### 2.5 推论五：推理时没有反馈闭环

训练时 loss 是唯一反馈；推理时模型收不到「结果对不对」的信号。可靠性完全取决于有没有外部回路把真值喂回来。

- **代码生成**：可运行 + 有测试 → 编译器/测试就是真值反馈 → 错误可检测可修正 → 可靠。
- **Agent + 工具**：工具返回结构化的成功/失败 → 反馈闭环 → 可编排多步。
- **自由对话/一次性文案**：没有任何外部验证 → 只能靠模型自洽 → 错误不可见。

闭环是可靠性来源，不是模型能力。

### 2.6 推论六：不可逆后果是系统原理，不是模型原理

任何概率系统都有错误率 $\epsilon > 0$。期望损失 $= \epsilon \times \text{后果}$。

- **可回滚**（草稿、建议、代码 review）：后果有限，$\epsilon$ 可以容忍 → 适合全自动。
- **不可逆/高后果**（支付、删库、发生产）：后果趋近无穷 → 无论 $\epsilon$ 多小都不能裸用 → 必须人工审批闸门。

这不是「AI 不适合」，是「任何不可验证的自动化都不适合承担不可逆后果」。

## 三、四层分级：把原理翻译成操作标尺

有人把适用度分四层：**强适用 / 次适用 / 慎用 / 不建议**。这四层不是「能力高低」，是任务目标与训练目标的夹角。

| 层 | 原理对应 | 判据（缺一即降层） |
|---|---|---|
| **强适用** | 正确性来自语言分布 + 有反馈闭环 + 可回滚 + 量大 | 四条件**全满足** |
| **次适用** | 正确性来自语言，但闭环弱或需品牌/事实把关 | 缺「闭环」或缺「可回滚」其一 |
| **慎用** | 正确性来自外部事实/精确值，或后果高需人终审 | 缺「容错」或「后果可控」 |
| **不建议** | 不可逆 + 终局判定，或硬拿 AI 补确定性短板 | 命中红线 |

夹角越小越强适用。

## 四、行业定位：按环节切，不按行业贴标签

按行业分（研发、内容/运营、客服/销售、办公、视觉、风控/金融、教育、硬件/嵌入式、自动驾驶/机器人）是应用地图，但有个根本缺陷：**同一个行业内部，不同「环节」落在不同层**。下面是各行业主力环节的定位 + 最该警惕的环节。

| 行业 | 主力环节定位 | 原理依据 | 红线/警惕环节 |
|---|---|---|---|
| **研发** | **强适用** | 编译器+测试=天然闭环；git=天然可回滚；量大 | Agent 化落不落地取决于 API 干净度，不取决于模型 |
| **内容/运营** | 强适用→**次适用** | 初稿强适用（量大、可回滚、错了非致命）；发布前需事实核验 | 事实型内容不能裸发，需检索/人工终审 |
| **客服/销售** | **次适用**→慎用 | 标准问答有知识库=检索闭环；但承诺/价格/合同=可追责 | 销售承诺、报价=终局判定边缘，慎用 |
| **办公** | 强适用→**慎用** | 摘要/纪要/翻译强适用；财务核算=确定性短板 | 报表数字、报销金额硬算=自找麻烦 |
| **视觉** | 生成强适用 / 检测**慎用** | 生成：模糊+可迭代回滚；检测：正确性来自外部真值 | 工业质检、医疗影像=后果高，需人终审 |
| **风控/金融** | **慎用**→不建议 | 初筛/异常检测可辅助（可回滚）；放贷=终局判定 | 终局放贷判定=红线；数据出网=红线，双命中 |
| **教育** | **次适用**→慎用 | 个性化练习/批改初稿强适用；评分定级=终局判定 | 成绩定级、心理疏导=责任不可让渡 |
| **硬件/嵌入式** | **慎用** | 代码辅助可（次适用），但时序/内存/寄存器=精确符号 | 位级运算、寄存器操作=确定性短板（推论三） |
| **自动驾驶/机器人** | **不建议** | 物理不可逆 + 生命安全 + 终局判定=双红线全中 | 感知可辅助，**决策（刹车/转向）不可交 AI** |

**教育是张力最佳案例**：教学辅导和成绩定级在同一个行业，前者强适用、后者命中终局判定红线。**这证明正确粒度是「任务/环节」，不是「行业」。**

## 五、三句「实话」的压力测试

### 5.1 「甜区是模糊但量大——烦、做不完、错了不致命」

**对，但不精确。** 精确表述是四条件交集：

$$\text{甜区} = \text{模糊(容错)} \cap \text{量大(值得自动化)} \cap \text{可回滚(错不致命)} \cap \text{可验证/有闭环}$$

「视觉检测」是「**确定**但量大」——只满足后三个，所以落**慎用**而非强适用。风控是「确定+量大+**不可回滚**」——量大从加分项变成**风险放大项**。所以「量大」单独不是甜区条件，它是经济性前提，同时也是后果的乘数。

### 5.2 「别拿 AI 补确定性短板，正确姿势是让 AI 写调用、让程序去算」

**完全正确，且是推论三的直接应用。** 连续向量表示没有精确符号存储，算术必须交给离散符号系统（程序）。更深一层：这句话的正确性是**结构性的**——不是「模型不够强」，是「输出空间错了」。再强的 LLM 算 $a \times b$ 也是在连续空间里近似，不如一行代码在整数域里精确。**「AI 写胶水、程序干确定性」= 让每个子系统待在它擅长的输出空间里。**

### 5.3 「2026 分水岭是 Agent 化，取决于干净 API + 可回滚操作」

**对，但还差一个条件。** 「干净 API + 可回滚」还不够，必须补第三条：**API 返回的结果本身可判定对错（有真值）**。

- 调「执行测试」的 API → 返回 pass/fail，有真值 → 闭环成立。
- 调「生成营销文案」的 API → 返回一段文字，**没有 ground truth** → 闭环仍断，Agent 照样不可靠。

精确表述：

$$\text{Agent 落地} = \text{干净 API} \cap \text{可回滚操作} \cap \text{可验证真值}$$

这正好是推论五（闭环）的完整条件。

## 六、统一选型判据

把一个任务丢进下面五个问题，答案决定落哪层：

1. **正确性来自哪？** 语言分布 → 继续；外部事实/精确值 → 直接**慎用**起步。
2. **有干净 API 且结果可验证吗？** 有 → 强适用候选；无 → 降**次适用**。
3. **错了能回滚吗？** 能 → 继续；不能 → 直接**慎用/不建议**。
4. **量大吗？** 大 → 值得自动化；小 → 可能不值，别为了用而用。
5. **最终判定权在谁？** 在人 → 可以深度辅助；在 AI → **命中红线，不建议**。

五个答案落到一个格子里：

```text
正确性=语言 且 闭环 且 可回滚 且 量大 且 人在环上 → 强适用
                   缺闭环/缺回滚 或 需事实把关       → 次适用
正确性=外部事实 或 不可回滚 或 后果高               → 慎用
不可逆 或 终局判定归AI 或 拿AI硬算确定性            → 不建议
```

## 七、两条红线

### 7.1 人不能有的责任 AI 不能有（终局判定）

「终局判定权归人」不等于「AI 不碰这个领域」。AI 可以提供证据、草拟、初筛、给置信度——这些都是**辅助**，不越权；只要最终决定权在人，AI 可以深度参与。红线针对的是「无人值守的终局判定」，不是「AI 参与」。校准过的概率（如 System One 决策模型）把判定权交还给人，正是正确用法。

### 7.2 不该出网的数据别出网

这是第一性要求，不是偏好。一旦数据出网，就交出了**可验证性和可回滚性**——无法审计、无法撤回、无法确定它流向哪里。这是对「私有部署 vs 云端 API」的硬约束：红线圈定了模型部署位置，进而圈定了可用的模型。金融、硬件 IP、医疗、政府数据都在此列。

## 结论

三套框架（四层、行业、实话）彼此自洽，都收敛到同一条原理链：**正确性来源 + 反馈闭环 + 可回滚 + 终局责任**。分歧点只有两处，也是最有价值的两处：

1. **「量大」是双刃剑**——它是自动化经济性的前提，同时是后果的乘数。甜区必须同时满足「容错 + 量大 + 可回滚 + 可验证」，四缺一就降层。
2. **正确粒度是「任务/环节」不是「行业」**——教育、风控、视觉都证明了同一行业内强适用与红线并存。

最终压缩成一句判语：**「模糊、量大、可回滚、可验证的辅助活 → 交 AI；确定、致命、不可逆、要担责的判定 → 留在人手里。」**
